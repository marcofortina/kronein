Kronein Core
===========

Intro
-----
Kronein is a new peer-to-peer cryptocurrency network derived from Kronein Core.
Kronein Core provides the reference node, wallet, and graphical application.

The software is currently pre-release. Its production network parameters have
not yet been frozen, so it must not be used to secure funds.

Setup
-----
Unpack the files into a directory and run bitcoin-qt.exe. Executable names are
temporarily inherited from the upstream codebase.

Kronein Core downloads and validates the complete Kronein blockchain. Storage and
synchronization requirements will be documented before the production launch.

For documentation and issue reporting, visit:
  https://github.com/marcofortina/kronein
